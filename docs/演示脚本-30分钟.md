# 30 分钟演示脚本

> 2026-10-08 ｜ 规则包 `rp-2026.10.gd-pilot-standard.v3` ｜ 全程离线，不需要云凭证
> 每步给「命令 → 期望看到什么 → 一句话讲什么」。凡标 **未做** 的步骤本期不存在，不要现场编。

## 0. 准备（约 2 分钟）

```bash
uv sync                                                  # 唯一的依赖通道：按 uv.lock 精确重建 .venv
cp .env.example .env                                     # 全不填也能跑：默认 provider=stub
uv run python -m pytest tests/test_dependencies.py -q     # 先对账 pyproject / uv.lock / 当前环境
```

讲清依赖口径这一句：**依赖只走 uv**（2026-10-09 决定，需求文档已同步修订到 v2.1，裁决 D-07），
`uv sync` 建的 `.venv` 里没有 pip。被问到「为什么不用 requirements.txt」的标准答法：
**旧的手写清单实测漏钉了 `fastapi` 的核心传递依赖 `opentelemetry-api`（只写 `>=1.44.0` 浮动），
「锁版本可复现」当时并不成立**；`uv.lock` 带全闭包 217 条 sha256，
并由 `tests/test_dependencies.py` 对账「声明 / 锁 / 实装环境」三份口径——换 uv 时传递依赖被钉回实测版本
（pydantic 仍 2.13.5），因为所有数字是在那个环境上测的，换工具不许顺手改测量基线。

讲法：单人自主作品集，数据 100% 合成，法条基准公开可查，没有真实用人主体。

## 5. 举证包与外部重放（约 4 分钟）

```bash
python -m src.cli report
python -m src.cli verify
python -m src.cli export --record-delivery-as rv1   # 先登记交付事件（非密码学签名），再导出
python -m src.cli replay var/packages/<run_id>.zip   # 把包内输入喂回引擎，比对三元组
python -m src.cli ask "国庆当天上班加班费按几倍算" --as E004
python -m src.cli covers
```

期望：
- `verify` 审计链逐条校验通过；改一条 → 报断链下标（`tools/mutation_test.py` 的 M7 就是这个反例）。
- `export --record-delivery-as rv1` 先追加一条 `evidence.sign` 审计事件（**只登记交付，不是密码学签名**），
  再产出 zip；旧别名 `--sign-as` 仍可用。包内五件产物要当场点开讲：
  `conclusions_final.csv`（**只有已登记具名人工结论的条目**，其余全在 `findings.csv` 里等处置）、
  `responsibility.json`（机器算了什么 / AI 碰过哪些问答 / 人确认了什么 / 谁登记的交付）、
  `not_covered.json` 与 `未覆盖清单.md`（本期不判什么、哪些没测，自己先说）、
  `inputs/`（本次结论真正依赖的原始 CSV + `inputs/manifest.json` 记的每个文件 sha256）。
  未登记交付时 `responsibility.signed = false`，界面与 CLI 都不把它显示成已签发/已签名。
  0.4.18 起新包字段为 `delivery_registered`，旧包回落 `signed`；两字段并存且不一致即验算失败。
- `replay <包>` 输出三元组逐项 `=`，退出码 0。**这一段是整场演示最硬的一句**：
  复核方不需要相信我，也不需要另外找我要数据——包自己带着输入。
  现场演示反例：把包解压后改 `inputs/…punch.csv` 里一个收工时间再 `replay`，必须报
  `≠ conclusion_digest`（`tests/test_replay.py::test_replay_catches_a_swapped_input_file` 就是这个用例）。
- 不带代码也能验一半：解压后 `python verify.py`（只用标准库）会打印
  `CHAIN OK` + `INPUTS OK checked=7` + 三元组。它证明"包没被改写"，不证明结论——这句要说出口。
- `ask` 输出 `gate_decision`、倍数档位、可点开出处、证据覆盖率；问"该付多少钱"→
  **只解释规则不给数**并自动开复核单（`EXPLAIN_ONLY`）。
- `covers` 列出本期覆盖与未覆盖判据。
讲法：结论 = 规则版本 + 输入指纹 + 结论摘要 三元组；包内自带 `verify.py`，
复核方不必相信我，自己重算链即可。

## 7. 服务启停（可选，约 2 分钟）

```bash
uv run python tools/start_services.py
uv run python tools/stop_services.py --status
uv run python tools/stop_services.py
```

**为什么必须 `uv run`**：启动器把服务清单里的 `<python>` 换成"调用方自己的解释器"。
在 cmd 里用全局 python 直跑，服务子进程就会用那个环境，起来就死在
`ImportError: cannot import name 'sentinel' from 'typing_extensions'`。
现在这种用法会在**预检阶段**被拦下（`missing-interpreter-deps`），并直接告诉你该敲什么命令，
不再等 30 秒超时后把矛头指向"端口被占"。

期望：启动到就绪约 1.4 s、优雅停止约 0.8 s，停止后端口释放、WAL 落盘、连接账本收支平衡。
边界：本机单用户进程管理，不是 systemd 替代品。
