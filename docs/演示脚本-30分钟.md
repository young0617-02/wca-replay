# 30 分钟演示脚本

> 2026-10-08 ｜ 规则包 `rp-2026.10.gd-pilot-standard.v3` ｜ 全程离线，不需要云凭证
> 每步给「命令 → 期望看到什么 → 一句话讲什么」。凡标 **未做** 的步骤本期不存在，不要现场编。

## 0. 准备（约 2 分钟）

```bash
python -m venv .venv && source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                     # 全不填也能跑：默认 provider=stub
```

讲法：单人自主作品集，数据 100% 合成，法条基准公开可查，没有真实用人主体。

## 1. 一条命令跑完整链（约 4 分钟）

```bash
python -m src.cli all
```

期望：生成 → 导入 → 建库 → 校验 → 报表 → 举证包六步依次打印；结论约 101 条（12 员工 × 242 天）。
讲法：这一条命令就是评审者复跑用的入口，界面（**本期未实现**）只是它的一层皮。

## 2. 确定性测试与无凭证隔离（约 5 分钟）

```bash
python -m pytest tests/ -q -m "not llm"
```

期望：**124 passed / 1 deselected / 3 failed**；3 条失败是支撑文档缺项（见 `reports/`），不是代码坏。
讲法：`-m "not llm"` 筛掉的是**唯一**需要真实云凭证的用例；剩下 124 条不联网、不调模型。
这条是需求 NFR-19 的落点：改用云 API 之后，评审者仍然一分钱不花就能验实现。

## 3. 判据可复核：变异测试（约 6 分钟）

```bash
python tools/mutation_test.py
```

期望：注入 17 个真实缺陷（倍数写错、ACL 改成先召回再过滤、审计链 prev 写死、
允许报酬类下违规结论、重大事项直接给金额……）**捕获 19 个，还原 MD5 全部一致**。
讲法：测试套件有鉴别力，不是空转；报告落在 `reports/变异测试.md`。

## 4. 评测七项指标（约 4 分钟）

```bash
python evals/judge.py --write-report
```

期望：意图 Top-1 70/70 · Hit@5 37/37 · MRR 0.664 · 工具调用 30/30 · 引用忠实 70/70 ·
**错承诺 0 条** · **越权召回 0 条**；红线不为 0 时退出码非 0。
讲法：70 条题（检索 29 / 数值 24 / 混合 16 + 跨城隔离回归 1）的标准答案都写成**手工推导式**（`derivation` 字段），避免引擎给自己打分；
数字全部来自离线 stub 轨，云轨**未测**（口径见 `docs/口径声明.md`）。

## 5. 举证包与外部重放（约 4 分钟）

```bash
python -m src.cli report
python -m src.cli verify
python -m src.cli export --sign-as rv1        # 先签发（具名进审计链），再导出举证包
python -m src.cli ask "国庆当天上班加班费按几倍算" --as E004
python -m src.cli covers
```

期望：
- `verify` 审计链逐条校验通过；改一条 → 报断链下标（`tools/mutation_test.py` 的 M7 就是这个反例）。
- `export --sign-as rv1` 先追加一条 `evidence.sign` 审计事件，再产出 zip。包内四件新产物要当场点开讲：
  `conclusions_final.csv`（**只有已登记具名人工结论的条目**，其余全在 `findings.csv` 里等处置）、
  `responsibility.json`（机器算了什么 / AI 碰过哪些问答 / 人确认了什么 / 谁签的字）、
  `not_covered.json` 与 `未覆盖清单.md`（本期不判什么、哪些没测，自己先说）。
  没签发时 `responsibility.signed = false`，界面与 CLI 都不假装已签发。
- `ask` 输出 `gate_decision`、倍数档位、可点开出处、证据覆盖率；问"该付多少钱"→
  **只解释规则不给数**并自动开复核单（`EXPLAIN_ONLY`）。
- `covers` 列出本期覆盖与未覆盖判据。
讲法：结论 = 规则版本 + 输入指纹 + 结论摘要 三元组；包内自带 `verify.py`，
复核方不必相信我，自己重算链即可。

依次演示并讲清"权限在服务端"：
1. `op1` 登录 → 视图① 上传 `data/raw/punch.csv` → 显示的**文件指纹与行数**与 `python -m src.cli ingest`
   打印的一致（两通道调用同一个 `import_csv_file`）；选城市档发起校验 → 头部显示城市与规则版本。

4. `rv1` 点"签发并导出" → 包名与 `python -m src.cli export` 产出的三元组一致（同一个 `export_package`）。
