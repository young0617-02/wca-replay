# 0.4.11 冻结版本说明（对外 PoC 冻结版）

> 本文件说明 0.4.11 的冻结范围、与 0.4.10 的关系、摘要不变量与历史版本保留清单。
> 对外交付以 **0.4.11** 为准；0.4.10 只作为历史验收基线保留，不再更新。

## 1. 冻结结论

- **0.4.11 是当前对外 PoC 冻结版**。
- 0.4.11 相对 0.4.10 **仅文档与生成脚本变更**：修正 5 项文档/判据一致性问题，
  并新增本冻结说明；**无规则语义变更**，引擎、规则包与摘要算法均未修改。
- 0.4.10 为历史验收基线：`dist/wca-replay-0.4.10/` 与
  `handoff/20261104-第十二轮整改/` **一律不改动**。

| 项 | 内容 | 落点 |

## 4. 版本与 wheel 配对

- **0.4.11 的举证包必须配 0.4.11 wheel 验算**（`producer` 版本/commit 与 wheel 不一致会
  `PRODUCER FAIL`，属配对问题，不是篡改）。
- **0.4.10 wheel 必须保留**，用于验算 0.4.10 及更早的历史包；清单见交接包 `OLD-WHEELS.md`。
- 0.4.4–0.4.8 旧 wheel 不做 `comparability_scope` 判定；0.4.9 起才有。
