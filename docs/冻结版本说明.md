# 0.4.13 冻结版本说明（对外 PoC 冻结版）

> 本文件说明 0.4.13 的冻结范围、与 0.4.12 / 0.4.11 / 0.4.10 的关系、摘要不变量与历史版本保留清单。
> 对外交付以 **0.4.13** 为准；0.4.10 为历史验收基线；0.4.11、0.4.12 曾冻结但**未对外**。

## 1. 冻结结论

- **0.4.13 是当前对外 PoC 冻结版**。
- 0.4.13 修复第二轮盲验发现的**阻断性功能缺陷**：默认 `wca all` 导出的 v2 无签名包，被
  自家 `wca-verify` 判 `INPUTS FAIL —— 缺少 manifest.inputs_digest`、exit 1；
  同时 `docs/签名方案.md` 写“无签名仍通过”，三处口径互相对不上。
- **0.4.12 未对外**，原因一句话：默认流程产物被自家验算器判 `RESULT FAIL`（exit 1），
  属阻断交付的功能缺陷；且 `RELEASE.json` / `release/README-验收.md` 仍写
  “`SHA256SUMS` 覆盖全部发行文件”，与实物 5 行不符。0.4.12 发行物与第十四轮交接**保留只读**。
- **0.4.11 曾冻结但未对外**：其发行 README 保留“v6 新包配 0.4.8 wheel”的 0.4.8 时点旧句，
  接收方照做会 `PRODUCER FAIL`。
- 0.4.10 为历史验收基线。
  `dist/wca-replay-0.4.10/`、`0.4.11/`、`0.4.12/` 与第十二、十三、十四轮交接**一律不改动**。

八包 `conclusion_digest` 逐包相同：

不代表数据或结论变化；本轮修复不触碰规则语义。

## 3. 0.4.13 修复的 5 项

| 项 | 内容 | 落点 |
| --- | --- | --- |
| 阻断 1 | 验算器按包内 `schema_version` 分流：schema v3 缺 `inputs_digest` 仍 `FAIL`（exit 1）；schema v2 缺该字段为**版本缺失**，记 `NOT CHECKED`、不参与 `RESULT OK` 门禁，最多 `RESULT PARTIAL`（exit 2） | `src/package_verify.py`、`src/verify_pkg.py` |
| 阻断 2 | 默认流程产物可被自家验算器正确判定：有签名钥自动导出 v3；无钥导出 v2 时 CLI/README/签名方案统一写明“只能 PARTIAL（exit 2），不能作为完整验收” | `src/cli.py`、`README.md`、`docs/签名方案.md`、发行模板 |
| 签名错话 | `RELEASE.json` 与 `release/README-验收.md` 不再写“`SHA256SUMS` 覆盖全部发行文件”，如实写明只覆盖 **5 个顶层文件**，`old-wheels/`、`old-packages/` 及签发后追加文件不在保护范围 | `scripts/build_release.py` + 0.4.13 重出重签 |
| 过度降级 1 | `未随交付清单.md` 不再说 `src/*.py` 不随交付；改为“源码随 wheel 提供（可用于 diff 复核），仓库内测试/脚本不随交付” | 第十五轮交接 |
| 过度降级 2 | “0.4.11→0.4.12 仅文档与脚本变更”已可独立复现：README 给出 wheel diff 命令，外部人可自证仅版本号与 `policies/RULE-PACK.md` 变化 | `README.md` + 第十五轮交接 |

`OLD-WHEELS.md` 另对 0.4.6 的 key_id 疑点加注：该版签名钥属误用、后果、以及为何不影响
0.4.7 起口径；目录内不可验证的原因一并写明。

## 3.1 0.4.11→0.4.12 的变更性质（可独立复核）

0.4.12 相对 0.4.11 **仅文档与生成脚本变更，无规则语义变更**。该结论不再依赖仓库：
`README.md` 给出 wheel diff 命令，对两版 wheel 逐文件比 SHA-256，实测只有
`policies/RULE-PACK.md`、`src/__init__.py`（版本号）、`src/_release_info.py`
（版本号/BUILD_COMMIT）变化，`src/` 其余模块逐字节相同。外部人只拿两版 wheel 即可自证。

## 5. 版本与 wheel 配对

- **0.4.13 的举证包必须配 0.4.13 wheel 验算**（包内 `producer.version` 与 wheel 版本不一致会
  `PRODUCER FAIL`，属配对问题，不是篡改）。
- **0.4.10 / 0.4.11 / 0.4.12 wheel 必须保留**，用于验算对应历史包；交接内清单位于
  `release/old-wheels/`，见 `OLD-WHEELS.md`。
- 0.4.4–0.4.8 旧 wheel 不做 `comparability_scope` 判定；0.4.9 起才有。
