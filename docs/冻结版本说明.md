# 0.4.12 冻结版本说明（对外 PoC 冻结版）

> 本文件说明 0.4.12 的冻结范围、与 0.4.11 / 0.4.10 的关系、摘要不变量与历史版本保留清单。
> 对外交付以 **0.4.12** 为准；0.4.10 为历史验收基线，0.4.11 曾冻结但**未对外**。

## 1. 冻结结论

- **0.4.12 是当前对外 PoC 冻结版**。
- 0.4.12 相对 0.4.11 **仅文档与生成脚本变更**：修复 4 项交付可用性问题（README 版本配对
  硬编码、交接路径不可达、安全现状文档引用未交付、PoC 边界缺失）；**无规则语义变更**，
  引擎、规则包与摘要算法均未修改。
- **0.4.11 曾冻结但未对外**，原因一句话：其发行 README 保留“v6 新包配 0.4.8 wheel”的
  0.4.8 时点旧句，接收方照做会 `PRODUCER FAIL`。
- 0.4.10 为历史验收基线；0.4.11 的发行物与第十三轮交接保留只读。
  `dist/wca-replay-0.4.10/`、`dist/wca-replay-0.4.11/`、`handoff/20261104-第十二轮整改/`、
  `handoff/20261104-第十三轮整改/` **一律不改动**。

## 2. 摘要不变量（0.4.12 必须与 0.4.11 / 0.4.10 逐字节相同）

- 四主包 `evidence_digest` = `ed3b3f1b…`

## 3. 0.4.12 修补的 4 项（均为文档/生成脚本）

| 项 | 内容 | 落点 |
| --- | --- | --- |
| 必修 1 | 删除“v5 配 0.4.7 / v6 配 0.4.8”硬编码；改为“`producer.version` 必须与 wheel 版本一致，不一致即 `PRODUCER FAIL`” | `scripts/build_release.py` 模板 + 0.4.12 README |

## 5. 版本与 wheel 配对

- **0.4.12 的举证包必须配 0.4.12 wheel 验算**（包内 `producer.version` 与 wheel 版本不一致会
  `PRODUCER FAIL`，属配对问题，不是篡改）。
- **0.4.10 / 0.4.11 wheel 必须保留**，用于验算对应历史包；交接内清单位于
  `release/old-wheels/`，见 `OLD-WHEELS.md`。
- 0.4.4–0.4.8 旧 wheel 不做 `comparability_scope` 判定；0.4.9 起才有。
