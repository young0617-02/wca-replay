## 二、你要按顺序做的动作

```bash
pip install -r requirements.txt          # 新增 Jinja2/MarkupSafe（无 node、无构建）
python -m src.cli all                    # 重建 v4 的库与举证包（先导入主数据，再登录）
python -m src.cli export --sign-as rv1   # 签发 + 导出；包内四件新产物见 reports/判据修订.md REV-06
python tools/start_services.py           # 起界面：http://127.0.0.1:8000
#   演示账号（口令只在 config/users.json 存哈希，明文见 docs/演示脚本-30分钟.md）
#   op1 / rv1 / em1 / ad1 —— 先看视图①，再用 rv1 看复核台
python tools/stop_services.py            # 用完停掉
```
1. **要接云 API 时**：把 `.env` 的 `WCA_LLM_PROVIDER` 设为 `cloud`（或仍用 `openai`，已是别名）、填 `WCA_CLOUD_BASE_URL/WCA_CLOUD_API_KEY`，
   然后跑一次 `python evals/judge.py --write-report` 并把云轨数字**与 stub 轨分开写**进 `docs/口径声明.md`。
   本轮我**没有用你 `.env` 里的 key 发过任何一次请求**（服务全程以 `WCA_LLM_PROVIDER=stub` 启动）。
2. 要改演示账号：`python -m src.cli users --username 名称 --emp E001 --roles OP --password '<口令>'`
   （`--emp` 必须是已导入的员工，否则命令直接拒绝并说明原因；口令只以 scrypt 哈希落盘）。
3. 待填仍未答的问题在 `docs/待确认清单.md`（第 4~7 项会限定制判覆盖面）。
4. 判据已冻结（`reports/判据修订.md` 文末）：要动 `src/rules/**` 或 `config/region_profile.json`
   的结论语义，必须先升 `WCA_RULE_PACK` 版本再补 REV，代码里的版本守卫会拒绝"改了判据没升版本"。
